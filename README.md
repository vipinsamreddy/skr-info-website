# SKR INFO LIMITED

Production-ready starter website for SKR INFO LIMITED.

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

1. Push these files to the `vipinsamreddy/skr-info-website` GitHub repository.
2. Sign in to Vercel with GitHub.
3. Import `skr-info-website`.
4. Vercel will detect Next.js automatically.
5. Click Deploy.
6. Add your custom domain under Project > Settings > Domains.
